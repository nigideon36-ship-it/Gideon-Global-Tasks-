# Gideon Global Tasks 🚀

A lightweight, responsive web application designed for interactive surveys and micro-task workflows. Built with clean front-end technology, this platform enables users to perform quick digital tasks, interact with survey interfaces, and preview task execution flows.

---

## 🌟 Key Features

* **Interactive Task Dashboard:** Intuitive interface for browsing available micro-tasks and surveys.
* **Responsive Layout:** Formatted for mobile devices, tablets, and desktop browsers using Tailwind CSS.
* **Single-File Architecture:** Clean HTML, CSS, and JS integration for rapid loading and execution.
* **Mock State Management:** Includes mock wallet balances, tier indicators, and interactive task status updates.

---

## 🛠️ Built With

* **HTML5:** Structural markup.
* **Tailwind CSS:** Modern utility-first CSS styling.
* **JavaScript (ES6+):** Dynamic UI toggles and client-side logic.
